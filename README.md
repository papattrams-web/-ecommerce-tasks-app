# E-Commerce Tasks App

This is a simple PHP and MySQL CRUD application made for E-Commerce Lab 01.

It allows a user to:

- create a task;
- view all tasks;
- edit a task; and
- delete a task.

## Live application

http://169.239.251.102:442/~kwame.attrams/tasks-app/

## Setup

1. Create or select a MySQL database.
2. Put the correct database details in `db.php`.
3. Run `setup.php` once to create the `tasks` table.
4. Open `index.php` to use the app.

The database password and database name in this public repository are placeholders. The real credentials are only used in the copy deployed to the school server.
